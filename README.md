# 📊 Excel Sales Dashboard

An interactive **Sales Analysis Dashboard built in Microsoft Excel** to analyze sales, quantity, profit, customer segments, regions, and quarterly performance.

## 📌 Project Overview

In this project, I transformed raw sales data into an interactive and visually appealing Excel dashboard using **data cleaning, PivotTables, PivotCharts, and Slicers**.

The dashboard helps analyze business performance from different perspectives and provides an easy way to filter and explore the data.

## 🛠️ What I Performed in This Project

### 1. 🧹 Data Cleaning & Preparation

* Checked the raw dataset for inconsistencies.
* Removed/handled unnecessary data.
* Checked for missing and duplicate records.
* Prepared the dataset for analysis.
* Verified data types and formatting.
* Organized the data into a structured format suitable for PivotTables.

### 2. 📊 PivotTables

Created PivotTables to summarize and analyze:

* Sales by year and quarter
* Quantity by product sub-category
* Quantity by customer segment
* Profit by region
* Sales and quantity across different dimensions

### 3. 📈 PivotCharts

Created interactive charts from PivotTables, including:

* Sub-Category Wise Quantity – Column Chart
* Segment Wise Quantity – Doughnut Chart
* Quarterly / Yearly Total Sales – Column Chart
* Region Wise Profit – Doughnut Chart

### 4. 🎛️ Interactive Slicers

Added Excel Slicers to make the dashboard interactive:

* **Ship Mode**

  * First Class
  * Same Day
  * Second Class
  * Standard Class

* **Segment**

  * Consumer
  * Corporate
  * Home Office

* **Region**

  * Central
  * East
  * South
  * West

The slicers allow users to dynamically filter the dashboard and explore different business scenarios.
